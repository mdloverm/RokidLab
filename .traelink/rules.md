# RokidLab Workspace Rules

## 强制引用文档
每次发起代码修改前，必须先读取并遵循以下文档：

### [docs/纠错方案.md](../docs/纠错方案.md)

该文档包含：
1. **项目架构与数据流** — 模块总图、依赖关系、协议定义
2. **错误类型分类与检查点** — 按模块分 7 大类、40+ 条检查项
3. **Master Checklist** — 修改前必须逐项完成的检查清单
4. **项目档案** — 所有文件的完整清单，必须随代码修改同步更新
5. **变更日志** — 每次修改必须追加记录
6. **已修复错误历史** — 供同类模式搜索和复盘参考

## 核心原则
1. 所有 ADB 消息消费 `CMD_CLSE` / `CMD_WRTE` 必须验证 `arg1 == localId`
2. 所有 `while(true)` 必须有超时保护
3. 新增资源（线程/Socket/Bitmap）必须确保释放路径
4. 每次修改后必须更新 `docs/纠错方案.md` 的第四部分（项目档案）和第五部分（变更日志）
